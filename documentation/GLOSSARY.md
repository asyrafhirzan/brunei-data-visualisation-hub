# Glossary

- **Tidy Data:** A standard way of mapping a dataset where each variable is a column, each observation is a row, and each type of observational unit is a table.
- **Manifest:** A JSON or YAML log file tracking downloaded files, source URLs, checksums, and ingestion timestamps.
- **Parser Tier 1:** Hand-written, custom Python parsing scripts tailored to specific complex or messy datasets.
- **Parser Tier 2:** Semi-automated generic parsers designed to ingest cleanly formatted tabular files without custom scripting.
- **Schema Drift:** Unannounced structural changes in source files (e.g., column renames, rearranged headers) that break automated ingestion scripts.
- **Evidence.dev:** An open-source business intelligence tool that lets you build web applications and static sites using Markdown and SQL.
